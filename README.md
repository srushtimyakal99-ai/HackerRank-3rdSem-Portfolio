## Optimization Reflection

While solving these HackerRank problems, I learned that writing a program that works is only the first step. It is also important to think about how efficiently the program uses time and memory. For Diagonal Difference, I accessed only the required diagonal elements instead of using extra arrays. This helped keep the auxiliary space constant. In Dynamic Array, I used the required sequence lists and calculated the index using the XOR operation with `lastAnswer`. For Sparse Arrays, I used a frequency dictionary so that each query could be answered efficiently instead of repeatedly searching through the complete list of strings. Time Conversion and Compare the Triplets require only a fixed number of operations, so their complexity remains constant. These problems helped me understand the practical difference between brute-force solutions and optimized solutions. I also learned to check time and space complexity before finalizing my code. Overall, this activity improved my understanding of arrays, strings, dictionaries, loops, conditions, and efficient problem solving. It also helped me become more comfortable with HackerRank and organizing programming work in GitHub.
